# 🍺 GitBar Homebrew

Install and update [GitBar](https://github.com/pedrotmr/git-bar) using Homebrew.

## Install

```sh
brew install --cask pedrotmr/git-bar/pedrotmr-git-bar
```

Or tap first for a shorter command:

```sh
brew tap pedrotmr/git-bar
brew install --cask pedrotmr-git-bar
```

## Update

```sh
brew upgrade --cask pedrotmr/git-bar/pedrotmr-git-bar
```

## Requirements

- macOS 14.6+ with Git installed.

Only stable releases are distributed.
